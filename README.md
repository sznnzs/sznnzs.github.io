# Zhenning Shi — Academic Homepage

Static academic homepage for [sznnzs.github.io](https://sznnzs.github.io/).
The layout and VuePress styling follow [whalexiao.github.io](https://whalexiao.github.io/),
with the content and assets replaced for Zhenning Shi.

## Local preview

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

The site has no build step or third-party runtime dependencies. Content lives in
`index.html`, presentation in `styles.css`, and the small navigation enhancement
in `script.js`.
